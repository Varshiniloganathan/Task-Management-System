# Task-Management-System
A simple web-based application to manage daily tasks effectively. Users can add, view, and categorize tasks as completed, incomplete, or important.
## Features
- Add new tasks
- Mark tasks as completed
- Track incomplete tasks
- Highlight important tasks
- View all tasks in one place
## Tech Stack
- **Frontend**: HTML, CSS, JavaScript, React.js
- **Backend**:  Node.js with Express.js
- **Database**: MongoDB
## Getting Started
### 1. Clone the Repository
git clone https://github.com/Varshiniloganathan/Task-Management-System.git
cd Task-Management-System
### 2. Start the Backend Server
cd backend
npm install
node app.js (or) nodemon app.js
Server will run at: http://localhost:3000
### 3. Start the Frontend (React)
cd frontend
npm install
npm start
